# 02.1. Từ Điển Ngôn Ngữ Chung (Ubiquitous Language)

## Bảng Thuật Ngữ Nghiệp Vụ Chuẩn Hóa

| Mã | Thuật Ngữ | Khái Niệm Kỹ Thuật | Định Nghĩa Nghiệp Vụ & Ràng Buộc Miền |
| :--- | :--- | :--- | :--- |
| `UL-01` | **Station** | Entity thuộc `AGG-CATALOG` | Điểm khởi hành hoặc điểm đến (Sân bay, Nhà ga, Bến xe) có mã định danh IATA/Code (VD: `HAN`, `SGN`). |
| `UL-02` | **Trip** | Aggregate Root `AGG-CATALOG` | Chuyến đi cụ thể có mã chuyến, thời gian đi/đến, loại phương tiện và danh sách ghế. |
| `UL-03` | **Seat** | Entity thuộc `AGG-CATALOG` | Vị trí ghế vật lý trên phương tiện, gồm số ghế (VD: `12A`) và loại ghế (`STANDARD`, `VIP`). |
| `UL-04` | **Hold Seat** | Command / UseCase | Hành vi tạm giữ ghế trong 10 phút, kích hoạt khóa phân tán trên Redis để ngăn chặn người khác chọn trùng. |
| `UL-05` | **Booking** | Aggregate Root `AGG-BOOKING` | Đơn giữ chỗ/đặt vé, đóng vai trò ranh giới giao dịch bảo đảm tính nhất quán của danh sách ghế đã chọn. |
| `UL-06` | **Booking FSM** | Finite State Machine | Máy trạng thái hữu hạn kiểm soát các bước chuyển trạng thái vé: `PENDING` $	o$ `HELD` $	o$ `CONFIRMED`. |
| `UL-07` | **Payment Reference** | Value Object / Identity | Mã tham chiếu duy nhất của giao dịch thanh toán gửi sang cổng VNPay (VD: `PAY_xxx`). |
| `UL-08` | **Idempotency** | Architectural Pattern | Cơ chế đảm bảo việc nhận lại cùng một Webhook IPN từ cổng thanh toán nhiều lần không làm sai lệch số dư/trạng thái. |
