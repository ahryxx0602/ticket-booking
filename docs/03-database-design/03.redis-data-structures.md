# 03.3. Cấu Trúc Dữ Liệu Redis (In-Memory Topologies)

## 1. `REDIS-CACHE-TRIP`: Cache-Aside Tra Cứu Lịch Trình
- **Key Pattern:** `trip:search:{departureCity}_{arrivalCity}_{departureDate}`
- **Kiểu dữ liệu:** `String` (JSON Serialize của `List<TripDto>`).
- **TTL (Time-To-Live):** `10 minutes` (600 giây).
- **Mục đích:** Giảm thiểu 90% tải truy vấn lên MySQL trong giờ cao điểm. Độ trễ phản hồi < 20ms.

---

## 2. `REDIS-LOCK-SEAT`: Khóa Phân Tán Vị Trí Ghế (Redisson RLock)
- **Key Pattern:** `lock:seat:{tripId}:{seatNumber}` (VD: `lock:seat:1:12A`).
- **Kiểu dữ liệu:** **Redisson RLock** (Lua Script Distributed Mutex).
- **Wait Time:** 2 giây (Thời gian tối đa chờ xếp hàng xin khóa).
- **Lease Time (TTL):** 10 phút (Khớp chính xác với thời gian phiên giữ chỗ).
- **Cơ chế:** Atomic Multi-Lock (Nếu chọn 3 ghế `12A`, `12B`, `12C`, bắt buộc khóa thành công cả 3; nếu 1 ghế thất bại sẽ tự rollback 2 ghế còn lại).
