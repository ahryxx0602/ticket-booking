# 05.1. Kiến Trúc Lục Giác & Phân Tầng (Clean / Hexagonal Architecture)

## 1. Nguyên Lý Phụ Thuộc (Dependency Rule)

Toàn bộ hệ thống tuân thủ nguyên lý đảo ngược phụ thuộc: **Tầng bên ngoài phụ thuộc vào tầng bên trong. Tầng Domain là trung tâm tuyệt đối, không phụ thuộc vào bất kỳ framework hay cơ sở dữ liệu nào**.

## 2. Trách Nhiệm Từng Tầng Kỹ Thuật

- **`ARCH-DOMAIN` (Domain Layer):** Chứa các Entity, Value Objects, Domain Enums, FSM logic và Interface Ports. Không có `@Entity`, `@Service`, `@Autowired`.
- **`ARCH-APP` (Application Layer):** Chứa các UseCases điều phối nghiệp vụ, chuyển đổi giữa Domain Entity và DTO, lắng nghe sự kiện nội bộ.
- **`ARCH-INFRA` (Infrastructure Layer):** Chứa code tương tác với hệ thống ngoài: Spring Data JPA Repositories, Redisson Client, Spring Security, Cổng thanh toán VNPay.
- **`ARCH-PRES` (Presentation Layer):** Chứa REST Controllers xử lý HTTP request, mapping JSON, kiểm tra tính hợp lệ của dữ liệu đầu vào.
